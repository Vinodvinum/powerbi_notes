📖 CHAPTER 13: FILTER CONTEXT vs ROW CONTEXT (🔥 CRITICAL)

🧠 Step 1: Why This Matters

You are at Amazon.

Manager says:

> “Why is this number changing when I click filters?”



👉 That is because of context


---

💡 Step 2: What is Context?

> Context means the environment in which a calculation is performed.




---

🔍 Step 3: FILTER CONTEXT

🧠 Definition

> Filter context is created by filters, slicers, or visuals.




---

🎯 Example

You select:

👉 City = Bangalore

Now:

SUM(orders[amount])

👉 Only Bangalore data is used


---

🧠 Meaning

👉 Data is filtered before calculation


---

🧾 Step 4: ROW CONTEXT

🧠 Definition

> Row context means calculation happens row by row.




---

🎯 Example (Calculated Column)

Profit = orders[sales] - orders[cost]

👉 Each row is calculated separately


---

⚡ Step 5: Key Difference

Feature	Filter Context	Row Context

Created by	Filters, slicers	Calculated column
Works on	Whole dataset	Each row
Used in	Measures	Columns



---

🔥 Step 6: CALCULATE & CONTEXT

👉 CALCULATE changes filter context

Example:

CALCULATE(SUM(orders[amount]), city = "Bangalore")

👉 Forces filter


---

🧠 Step 7: Real Example

Without filter:

👉 Total sales = 10000

With slicer (Bangalore):

👉 Total sales = 5000

👉 This is filter context


---

🎤 Interview Answer

“Difference between row context and filter context?”

> Row context applies calculations row by row, typically in calculated columns, while filter context filters the data before aggregation, typically used in measures and visuals.




---
